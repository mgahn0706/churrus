# 초능력자 사건 심문 콘텐츠 작성

관리 화면: `/scenarios/scenario/psychic/admin`

관리 화면에서 프롤로그, 페이즈, 지도 위 단서 위치, 조사 단서와 사진 경로, 인물 대화, 대화 선택지, 단서 조합별 신문, 폴백 응답을 편집할 수 있습니다. 초안은 해당 브라우저에 자동 저장됩니다. `초안 JSON`으로 백업하고 `초안 불러오기`로 복원할 수 있습니다. 완성 후 `TS 파일 저장` 또는 `코드 복사`로 내보내고, 결과를 `src/fixtures/psychic/interrogation.ts`에 적용하면 게임에 반영됩니다. 내보낸 TS 파일은 현재 원고를 완성된 데이터 형태로 펼쳐서 저장합니다. 브라우저 초안만 바꿔서는 게임 데이터가 변경되지 않습니다.

프롤로그, 페이즈별 독백, 조사 단서, 단서 조합별 신문 답변, 인물 대화 선택지, 폴백 답변은 [interrogation.ts](./interrogation.ts) 한 파일에서 관리합니다. 관리 화면에서는 같은 단서 ID의 조사 단서를 공유 항목으로 묶습니다. 표시할 페이즈를 선택하고, 내용이 바뀌는 페이즈에 새 버전을 작성할 수 있습니다. 변경 버전은 다음 변경 페이즈 전까지 이어집니다. 내보낸 원고에는 각 페이즈의 `sources`가 자동으로 펼쳐집니다. 기존 검색형 단서 파일인 `clues.ts`는 새 화면에서 사용하지 않습니다.

최종 제출의 선택 사항인 추가 질문은 A·B·C 각각의 초능력과 본명입니다. 비워 두어도 제출할 수 있습니다. 정답과 임시 본명은 [additionalQuestions.ts](./additionalQuestions.ts)에서 관리하며, 본명은 조사 단서에서도 확인할 수 있습니다. 제출한 답변은 결과 화면의 `추가 질문 해답` 탭에서 정답과 함께 표시됩니다.

프롤로그 대사는 글자가 차례로 나타나며, 클릭하거나 Enter/Space로 다음 대사로 넘어갑니다. 마지막 대사 다음에는 지도가 열립니다. `prologue`에는 문자열이나 `{ speaker, text, portrait }` 형식의 대사를 넣을 수 있습니다.

현재 초능력자 시나리오는 **오전 8시 → 오후 1시 → 오후 7시 → 다음 날 자정 → 최종 추리** 순서입니다. 조사와 심문은 각각 에너지 1을 사용합니다. 에너지가 남아 있어도 다음 페이즈로 진행할 수 있고, 모두 쓰면 경고를 본 뒤에도 계속 행동할 수 있습니다. 마지막 페이즈는 심문과 답변 제출만 가능합니다.

단서를 확보하면 용의자 또는 생존한 소장에게 단서 조합 하나를 제시해 신문할 수 있습니다. 선택한 단서 전체와 정확히 일치하는 인물·단서 조합은 해당 페이즈의 `interrogations(...)`에 적힌 대사 한 묶음으로 응답합니다. 없는 조합은 해당 인물의 `fallbackAnswers` 중 무작위로 응답합니다. 인물별 답변이 없으면 페이즈의 `fallbackAnswers`, 그것도 없으면 시나리오 공통 `fallbackAnswers`를 사용합니다. 관리 화면에서는 각 페이즈의 대화 탭에서 인물별 기본 신문 답변을 편집할 수 있습니다. 변경되지 않은 공유 단서는 한 번 획득하면 다음 페이즈에도 유지되며, 변경 페이즈부터는 새 버전으로 획득할 수 있습니다. 단서함에는 획득한 각 버전이 남습니다.

관리 화면의 신문 조합은 단서 이름과 내용을 검색해 체크박스로 선택합니다. 선택 결과는 이름으로 표시되며, 저장 시 필요한 단서 ID는 자동으로 기록됩니다.

같은 인물에게 같은 단서 조합으로 묻는 신문은 관리 화면에서 한 항목으로 묶습니다. 단서 조합과 기본 답변을 작성하면 단서가 표시되는 페이즈에 신문이 자동으로 나타납니다. 대사가 달라지는 페이즈에만 변경 답변을 작성합니다. 답변 화자는 신문 대상 인물로 고정되며, 플레이어 질문 대사는 나오지 않습니다. 기존 페이즈별 질문은 초안을 불러올 때 묶이며, 내보낸 원고에는 각 페이즈의 신문이 자동으로 펼쳐집니다.

단서함은 게임 안의 별도 탭이며 조사 단서와 인물 카드의 내용 열람만 가능합니다. 지도에서 단서를 누르면 해당 단서의 상세 모달이 열립니다. 신문 탭에서는 상단에서 인물을 선택하고 왼쪽 단서 그리드에서 여러 단서를 고른 뒤 오른쪽 신문 버튼을 누릅니다. 선택 단서 수와 관계없이 신문 한 번에 에너지 1을 사용합니다. 질문에 `revealedEvidence`를 지정하면 대사가 끝난 뒤 새 단서를 획득합니다. 지도 인물을 눌러 일반 대화를 시작하는 데는 에너지가 들지 않고, 대화 선택지로 질문할 때마다 에너지 1을 사용합니다. 대화 선택지는 페이즈마다 별개이며 관리 화면에서 현재 페이즈와 인물을 선택해 수정합니다.

지도에서는 작은 점이 조사 단서를, 인물 사진이 대화 상대를 뜻합니다. 지도 인물 사진을 누르면 지도 위에서 일반 대화만 열립니다.

`intro`, 일반 대화 `conversation`, 질문 `answer`에는 한 줄 문자열이나 여러 대사의 배열을 넣을 수 있습니다. 배열은 문자열과 `{ speaker, text, portrait }` 객체를 섞어 쓸 수 있으며, 플레이어가 각 줄을 눌러 다음 대사로 넘깁니다.

지도 단서에는 선택적으로 `password`를 설정할 수 있습니다. 잠긴 단서는 비밀번호를 맞히면 조사하고, 틀린 비밀번호를 제출할 때마다 해당 페이즈의 에너지 1을 사용합니다. 공유 단서의 비밀번호도 내용 변경 페이즈에서 바꿀 수 있습니다.

관리자에서 공유 단서마다 고정 번호를 부여합니다. 지도 설정과 단서 목록에 같은 번호가 표시되며, 페이즈별 표시 순서가 바뀌거나 새 단서를 추가해도 기존 번호는 유지됩니다.
공유 단서의 지도 위치도 모든 페이즈에서 같습니다. 어느 페이즈의 설정 지도에서 옮겨도 해당 단서가 표시되는 모든 페이즈에 적용됩니다.
같은 페이즈에 나오는 단서의 마커가 실제로 겹칠 때만 가까운 빈자리로 자동 배치합니다. 가까이 놓인 단서와 서로 다른 페이즈에만 나오는 단서는 그대로 둘 수 있습니다. 단서를 직접 옮긴 경우 그 단서의 위치를 우선 유지하고 주변 단서를 조정합니다.

관리자의 대화 탭에서 페이즈마다 등장 인물을 선택하거나 이름과 이미지 경로를 입력해 새 인물을 추가할 수 있습니다. 숨긴 인물의 대화 원고는 남아 있어 다시 표시하면 이어서 사용할 수 있습니다. 설정 탭 지도에서는 파란 인물 표시를 끌어 해당 페이즈의 위치를 정합니다.

신문에 제시할 단서는 최대 3개까지 선택할 수 있습니다. 관리자 원고와 게임 플레이에 같은 제한이 적용됩니다.

```ts
{
  id: "phase-1",
  title: "첫 번째 조사",
  intro: ["첫 번째 독백", "다음 독백"],
  timeLabel: "4월 14일 오전 8시",
  energyLimit: 3,
  mapImage: "/image/scenario/psychic/map/lab-map.svg",
  locations: [],
  sources: [
    {
      id: "p1-source-a",
      x: 48,
      y: 52,
      title: "조사할 장소나 기록",
      description: "",
      evidence: {
        id: "p1-evidence-a",
        title: "획득할 단서",
        description: "조사 후 단서함에 표시할 내용",
        image: "/image/scenario/psychic/clue/example.png",
      },
    },
  ],
  combinations: [],
  interrogations: interrogations("phase-1", [
    {
      suspectName: "실험체 A",
      evidenceIds: ["phase-1::p1-evidence-a", "phase-1::p1-evidence-b"],
      answer: ["처음에 듣는 진술", "다음에 듣는 진술"],
      revealedEvidence: {
        id: "p1-answer-clue",
        title: "조합으로 얻은 단서",
        description: "신문 대사가 끝나면 단서함에 들어갈 내용",
      },
    },
  ]),
  requiredCombinationIds: [],
  requiredQuestionIds: [],
}
```

- 신문은 마지막 페이즈에서만 열리며, 이전 조사에서 수집한 단서를 그대로 사용합니다. 답변을 들으면 해결됩니다. 이전 초안의 반박 대사는 불러올 때 신문 답변 뒤에 이어집니다. 관리자에서는 단서 1개를 고르면 등장 가능한 인물의 답변을 한 화면에서 바로 입력할 수 있고, 단서 2~3개 조합은 인물별 목록에서 편집합니다.
- 지도 이미지는 `mapImage`로 교체할 수 있습니다. 설정 탭 지도에서 번호가 붙은 주황색 단서를 드래그하면 위치가 저장됩니다. `source.x`와 `source.y`는 화면이 아닌 지도 이미지의 너비와 높이에 대한 백분율입니다. 지도와 점은 같은 16:9 좌표 영역에서 함께 크기가 바뀝니다. 기존 원고에 `locationId`만 있는 단서는 관리자에서 불러올 때 현재 표시 위치의 좌표로 변환됩니다.
- 다음 페이즈 버튼은 항상 나타납니다. `requiredCombinationIds`와 `requiredQuestionIds`는 콘텐츠 검증과 별도 진행 조건에 사용할 수 있지만, 현재 화면 이동을 막지는 않습니다.
- `combinations`는 기존 엔진의 단서 합성 규칙을 위한 필드입니다. 현재 초능력자 시나리오에서는 모두 빈 배열이며, 관리자 화면에서는 새 규칙을 만들지 않습니다. 이전 초안에 규칙이 있으면 기존 항목만 편집할 수 있습니다. 신문에서 여러 단서를 선택하는 기능은 `interrogations`에서 관리합니다.
- 같은 단서 ID는 다른 페이즈에서 다시 쓸 수 있습니다. 조합 입력과 질문의 `evidenceId`/`evidenceIds`는 `페이즈 ID::단서 ID` 형식이며, 단서 선택 순서는 결과에 영향을 주지 않습니다. `suspectName`은 인물 또는 소장 데이터의 이름과 같아야 합니다. 잘못된 참조는 빌드 중 오류가 납니다.
- 진행 상황은 브라우저의 `interrogation-psychic-v3` 저장 키에 보관되고 최종 답변 제출 시 삭제됩니다. 제출 답변은 결과 화면을 위해 별도 저장됩니다. 콘텐츠 구조를 크게 바꿔 이전 진행과 호환되지 않으면 저장 키의 버전을 올리세요.
- 현재 대사와 단서는 흐름 검증용 placeholder입니다. 정식 원고가 오면 `interrogation.ts`, `suspects.ts`, `answer.tsx`의 내용을 교체하세요.
